Trinket has shut down

Trinket shut down on August 31, 2026. The site is no longer operating, and trinkets, courses, assignments, and account data are no longer accessible.

Downloads are no longer available. Export tools were offered on the site in the months before shutdown, but they went offline with the rest of the service. We are not able to retrieve content or accounts.

Where to go instead

These platforms cover similar ground, and several published guides specifically for people coming from Trinket:

  • Pickcode: a coding platform with a guide for users transitioning from Trinket. Pickcode's Trinket transition guide
  • Dodona: free for teachers, supports 20+ languages, and their team can help convert Trinket content. dodona.be/en/trinket
  • Kita: a free collaborative browser-based computing platform with built-in assessment and AI, plus a migration guide. docs.getkita.org

These are independent services with no affiliation to Trinket. We encourage you to evaluate whether each fits your needs.

A community-hosted version

A community member at Strive Math runs a hosted version of the open source software at trinket.strivemath.org. It is independently operated and is not affiliated with, supported by, or monitored by Trinket, so we cannot speak to its availability or reliability, but it may be useful if you would like to keep working in a Trinket-style environment.

Content from trinket.io was not transferred there. It is a separate installation with its own accounts.

The open source release

The Trinket software was released as open source, and the code remains available for developers and organizations who want to run their own instance:

github.com/trinketapp/trinket-oss

Open source means the code is freely available. It does not mean the service continues, and it does not restore access to content that lived on trinket.io.
